# Planner ("Let Béa plan this trip"): function checklist

Source: `ItineraryImport.tsx` (Plan / Optimize / Compare), opened from Plan with Béa.

## Plan
- [ ] Build me a trip / I already have a plan
- [ ] Build: pace (Relaxed / Balanced / Full days), budget style (Value / Comfort / Premium), currency when costs are on, Approximate costs switch, description (500), Build my trip
- [ ] Import: paste text or a link ("Read this link" / "Read this itinerary"), Take a photo / Choose photos, Add a PDF or calendar file, "Read this PDF"
- [ ] Day one date for undated plans; Keep the trip's dates / Which dates are right
- [ ] Web-check note (events, closures) with Google's Search Suggestions and sources
- [ ] Result: stops with pins — Use this pin / Not this one / Béa's best guess / Check this one; Rebuild my trip; Ask Béa to find alternatives
- [ ] Nothing here is reserved — book hotels, tables and tickets yourself

## Optimize
- [ ] Goals: Closest together, Open when you get there, Rainy-day indoor, Easy mornings, Leave a rest day, Even pace, Meals first
- [ ] Anything else (free text), Ask Béa to rearrange
- [ ] Result: new order by day, walking before → after, Unscheduled, Use this arrangement, Undo

## Compare
- [ ] Plan A / Plan B (paste), What matters to you, Compare side by side
- [ ] Side by side / Measure / Day by day
- [ ] Pace, Highlights, Cost, Best for, Watch out; measures (Estimated cost, Places visited, Active hours, Walking, Transit, Longest single trip, Bad weather)
- [ ] Borrow this, How Béa decided, In Béa's words

## Not in the app (draft shows them)
- Optimize by travel style, accommodation, interests, accessibility, budget range, add/remove places — new; Optimize only reorders.
- Béa writing three itinerary options herself — new; Compare compares two plans you give it.
