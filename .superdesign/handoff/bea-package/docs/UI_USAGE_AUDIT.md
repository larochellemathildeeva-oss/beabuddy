# Béa UI Usage Audit

This audit incorporates the current UI-revamp direction for the Béa travel app.

## Core rule

**Béa is a character, not a decorative pattern.**

Use the mascot intentionally for:
- branding
- Companion guidance
- Plan with Béa
- meaningful loading / working moments
- occasional empty states
- selected major banners

Do **not** place Béa beside every feature. Functional screens should continue to rely primarily on typography, Lucide-style icons, maps, pins, cards, and clear controls.

## Universal loading treatment

For all qualifying operations:

**Heading:** `Béa is working on it…`

Then:
1. one small Béa animation
2. one short funny line
3. four animated loading dots

No task-specific subtitle.
No extra Béa icon next to the joke.
No fake percentage unless the backend exposes real progress.
Delay loader appearance about 250–350 ms to prevent flashing.
Once visible, keep it on screen at least ~650 ms so it does not flicker.
Rotate the joke only when a task lasts longer than about 4 seconds.

Recommended visible Béa size on mobile: **44–60 px tall** in compact contexts, or up to ~100–120 px on a dedicated full-screen loader.

## Screen / feature mapping

| UI / user action | Use Béa? | Action | Notes |
|---|---|---|---|
| **Plan with Béa — Build a trip** | YES | `run` | Full-screen loader after user submits trip criteria. |
| **Import existing itinerary / pasted plan / PDF/photo parsing** | YES | `think` | Use after submission while extracting/structuring trip content. |
| **Optimize trip** | YES | `think` | Full-screen or contained loader depending on flow. |
| **Compare itinerary options** | YES | `think` | Loader while alternatives are being generated/computed. |
| **Search recommendations / hidden gems** | YES | `dig` | Strongest use of digging animation and puns. |
| **Nearby recommendations from Map/Companion** | YES, if request is non-trivial | `dig` | Inline/contained loader preferred. |
| **Directions / route calculation** | YES | `run` | Use while initial route/travel times are calculated. |
| **Route recalculation** | YES, compact | `run` | Tiny inline treatment; do not cover live map unnecessarily. |
| **Companion asks Béa to solve/plan/recommend** | YES | based on task | `run`, `dig`, or `think`. |
| **Packing suggestions generated by Béa** | YES | `think` | Only while Béa is generating; normal checklist editing does not need mascot. |
| **Budget suggestions / cost synthesis generated by Béa** | YES | `think` | Use if computation is visibly non-instant. |
| **World — import a pasted list of locations** | YES | `think` | Good while geocoding/parsing many places into pins. |
| **World — add one location manually** | USUALLY NO | — | Use normal inline field/loading feedback unless network delay becomes meaningful. |
| **World — Map/Bucket list/Been there tabs** | NO by default | — | Keep map/pins/data visually primary. |
| **World — Stats** | NO for instant local stats | — | If Béa is explicitly analyzing or generating insights, use `think`. |
| **Trips — Companion landing/guidance** | OCCASIONAL | static/`think` | Character can appear intentionally in guidance, not continuously. |
| **Trip Map Live** | NO persistent mascot | — | Keep map usable. Only use a tiny loader for route/recommendation requests. |
| **Trip Map Split** | NO persistent mascot | — | Same rule as Map Live. |
| **Timeline editing / dragging / expanding travel instructions** | NO | — | Direct manipulation should feel immediate. |
| **Trip menu: Edit trip / People / Destinations** | NO | — | Standard UI. |
| **Trip menu: Offline sync** | NO | — | Use a standard sync/progress affordance; this is a utility operation, not Béa “thinking.” |
| **Delete trip / destructive confirmation** | NO | — | Never make a destructive wait state playful. |
| **Normal page navigation / tab switching** | NO | — | Avoid mascot fatigue. |
| **Initial app launch** | Prefer standard launch screen | — | Béa can be in branding, but do not play a work animation without actual work. |
| **Occasional longer-load Easter egg** | YES, sparingly | `ball` or `bone` | Use only after a task has already been loading for several seconds. |

## Recommended action logic

- `run`: itinerary generation, directions, routing, rerouting
- `dig`: recommendations, discovery, hidden gems, nearby search
- `think`: compare, optimize, import/parse, generated packing/budget help
- `ball`: rare longer-load personality beat
- `bone`: rare longer-load discovery beat

Do not randomly use ball/bone on every load. They work because they are occasional.

## Theme behavior

### Calm
- warm cream / ivory / beige
- restrained burnt-orange accent
- loading dots can use the burnt-orange accent

### Colorful
- white base
- playful mixed pastels
- use the active contextual pastel/accent token for loading dots

### Dark
- black / near-black
- cream / white text
- **dark-beige accent**
- do **not** use terracotta in Dark mode

Béa herself remains the white French bulldog with the lemon bandana in every theme.
